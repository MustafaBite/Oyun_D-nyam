# 🎮 Oyun_D-nyam

Tarayıcı üzerinden oynanabilen mini oyun koleksiyonu.  
Bu proje HTML, CSS ve JavaScript kullanılarak geliştirilmiştir.

## 🚀 Canlı Demo

🔗 https://mustafabite.github.io/Oyun_D-nyam/

---

## 📌 Proje Hakkında

Oyun_D-nyam, farklı türlerde mini oyunları tek bir platform altında toplamak amacıyla geliştirilmiş bir web oyun projesidir.

Projede kullanıcılar tarayıcı üzerinden çeşitli oyunları oynayabilir ve farklı oyun mekaniklerini deneyimleyebilir.

---

## 🎮 İçerdiği Oyunlar

### 🐱 CatRun
Refleks ve zamanlamaya dayalı koşu oyunu.

### 🔤 Adam Asmaca
Klasik adam asmaca oyununun web tabanlı versiyonu.

### 💰 Hazine Avcısı
Oyuncunun harita üzerinde hazineleri bulmaya çalıştığı keşif oyunu.
